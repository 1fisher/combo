# combo M1.5 设计:项目持久化 + 文件编辑 + 对话优化

日期:2026-08-01
状态:已评审(经 brainstorming 流程,用户确认)

## 1. 目标

在 M1 垂直切片(项目 → 会话 → agent 对话闭环)基础上,补齐三个能力:

1. **项目选择与自动记录**:左侧项目列表可选中项目,选中结果持久化到
   localStorage,刷新后自动恢复。
2. **打开项目与编辑文件**:选中项目后左侧栏变为项目文件树,点文件在右侧
   编辑器面板打开、编辑、保存。因 rune 的 HTTP API 没有文件读写端点,由
   combo-proxy 新增受限文件服务承担读写。
3. **对话界面优化**:消息气泡、Markdown 渲染、流式光标、工具调用展示的
   UI 打磨,按 frontend-design 方向重做调色与排版。

## 2. 布局

```
┌───────────────┬──────────────────────────────────────┐
│ 侧边栏(280px)  │ [会话 tabs ······ ＋]                  │
│ ┌───────────┐ │ ┌────────────────┬──────────────────┐ │
│ │ 项目名 ⏵    │ │                │  文件编辑器(可选)  │ │
│ │  └ 文件树   │ │   对话面板      │  打开文件 tabs     │ │
│ │            │ │   (消息/工具调用) │  + textarea 编辑器 │ │
│ │ [＋ 添加项目] │ │                │  (宽 480,可折叠)   │ │
│ └───────────┘ │ └────────────────┴──────────────────┘ │
└───────────────┴──────────────────────────────────────┘
```

- 未选项目 → 侧边栏为项目列表;选中后切换为项目文件树(顶部面包屑返回)。
- 点文件 → 右侧滑出编辑器,对话保持可见;编辑器可折叠。

## 3. 功能设计

### 3.1 项目选择与自动记录

- `agentStore` 使用 `zustand/persist` 持久化 `activeWorkspaceId` 与
  `activeSessionId`(`partialize` 只保留这两项,SSE 实时状态不入库)。
- 恢复容错:恢复的 workspace 不在列表时自动清除。

### 3.2 文件服务(combo-proxy `fs.rs`)

代理仅接管 `/v1/workspaces/{id}/files/*`,其余仍透传:

| 端点 | 说明 |
|---|---|
| `GET .../files/list?path=` | 列单层目录(相对路径,懒加载),返回 `{name, path, type, size}` |
| `GET .../files/content?path=` | 读文件(限 1MB;含 NUL 判定为二进制,返回 415) |
| `PUT .../files/content?path=` | 写文件(原子写:同目录 tmp + rename) |

安全:

- 代理先向 rune `GET /v1/workspaces/{id}` 取 workspace 真实路径。
- 相对路径逐段校验(`..`、绝对路径拒绝),canonicalize 最深已存在祖先,
  强制前缀在 workspace 根内,阻止目录穿越与 symlink 逃逸。

### 3.3 前端文件浏览与编辑

- 新 `stores/editorStore.ts`:打开文件列表、激活文件、脏标记、保存动作。
- 组件:`FileExplorer`(懒加载目录树)、`FileTabs`(文件名、脏点 `●`、
  可关闭)、`EditorPane`(`<textarea>` + 行号 gutter,Cmd/Ctrl+S 保存)。
- 不引入 Monaco(体积与网络依赖不可取),等宽字体编辑即可。

### 3.4 对话界面优化(frontend-design)

- **调色板**:底色带冷蓝墨色(替换纯灰黑),accent 为「rune 青」
  `oklch(0.78 0.12 210)`,脏文件徽标用琥珀 `oklch(0.72 0.13 70)`。
- **字体**:正文 Geist;文件树/路径/时间戳等宽栈(信息编码,非装饰)。
- **消息**:user 右对齐、assistant 卡片化;Markdown 代码块带语言徽标与
  复制按钮;流式尾部 `▍` 光标;meta 弱化。
- **空状态**:无消息时引导文案,邀请行动。
- **签名元素**:对话中出现的文件路径渲染为可点击 chip,点击直达编辑器;
  tool call 卡片带「打开文件」入口。「对话即导航」。

## 4. 测试

- Rust:`fs.rs` 单测 + `proxy_test.rs` 集成用例(列目录/读/写/穿越拒绝;
  stub upstream 增补 `GET /v1/workspaces/{id}`)。
- 前端:Vitest(持久化恢复、editorStore、文件树/编辑器组件)。
- 现有 e2e 中文选择器(输入项目路径/添加项目/发送/新建会话)不破坏。

## 5. 非目标

- 不做语法高亮编辑器、文件 diff 视图、LSP 诊断(属 M2)。
- 不做远端文件同步,纯本地读写。
